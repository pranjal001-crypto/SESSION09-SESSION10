# Session 09 & Session 10

## Personal Portfolio and Interactive Quiz

This project contains the work completed for Session 09 and Session 10.

The project focuses on building a personal webpage using HTML and CSS,
then adding JavaScript for themes, quiz interaction and state management.

---

## Session 09

### Topics Covered

- Building web pages with HTML
- Separating HTML and CSS
- Creating a personal profile page
- Creating a consistent color system
- Dark and light mode
- Responsive webpage design
- Testing the webpage

### Files

- `index.html` - Main landing page
- `personal_profile.html` - Personal profile page
- `assets/style.css` - Website styling
- `assets/theme.js` - Dark/light theme toggle

---

## Session 10

### Topics Covered

- JavaScript integration
- JavaScript state management
- Interactive quiz
- Score tracking
- Answer validation
- Instant feedback
- Restart functionality
- Responsive quiz design

### Files

- `quiz.html` - Interactive quiz webpage
- `assets/quiz.js` - Quiz questions and functionality
